# Data

This model is trained on an **eROSITA × DESI** matched sample, enriched with **WISE** photometry and
**Legacy Survey** image cutouts. All of the underlying data come from public surveys, but the raw
catalogs and the image cutout pool are large and are **not** tracked in this repository. This page
explains what you need, where to get it, and how `prepare-data` turns it into the staged files the
training code consumes.

## What is and isn't shipped

| Artifact | Size | In repo? |
|---|---|---|
| Split manifest (`aion_tvsplit_manifest.csv`) | ~0.9 MB | yes |
| Target coordinates (`aion_targetids_ra_dec_split_dr10_south.csv`) | ~1.6 MB | yes |
| Merged source catalog (`erosita_spectra_merged_32k.hdf5`) | ~1.9 GB | no — build locally |
| Legacy Survey FITS cutout pool (`fits_pool/`) | ~11 GB | no — download |
| Staged train/val/test HDF5 | ~1.9 GB | no — generated by `prepare-data` |
| Trained checkpoint | ~30 MB | no — train locally |

> This repository is the **model** (a clean reference implementation). The data-acquisition and
> cross-matching pipeline lives with the full research code; here we document the data contract and
> ship the frozen split so results are reproducible once you have the inputs.

## Public data sources

- **DESI DR1** — optical spectra and redshifts.
  DESI Collaboration (2025), [arXiv:2503.14745](https://arxiv.org/abs/2503.14745) ·
  data: <https://data.desi.lbl.gov>
- **SRG/eROSITA DR1** — X-ray source catalog (the `ML_FLUX_1` broad-band flux is the target).
  Merloni et al. (2024), A&A 682, A34, [doi:10.1051/0004-6361/202347165](https://doi.org/10.1051/0004-6361/202347165) ·
  <https://erosita.mpe.mpg.de/dr1/>
- **DESI Legacy Imaging Surveys DR10** — `griz` image cutouts (and WISE forced photometry).
  Dey et al. (2019), AJ 157, 168, [doi:10.3847/1538-3881/ab089d](https://doi.org/10.3847/1538-3881/ab089d) ·
  cutout service: <https://www.legacysurvey.org/viewer/cutout.fits>
- **AION** — the frozen multimodal foundation model providing the embeddings.
  Parker et al. (2025), [arXiv:2510.17960](https://arxiv.org/abs/2510.17960) ·
  `pip install polymathic-aion`, weights `polymathic-ai/aion-base`.

## Expected raw layout

`prepare-data` reads from this layout under `shareable_aion_flow/data/`:

```text
data/raw/erosita_desi/
  erosita_spectra_merged_32k.hdf5        # the merged source catalog (see below)
data/raw/legacysurvey/
  fits_pool/                             # one cutout per target: <targetid>.fits
data/manifests/
  aion_tvsplit_manifest.csv              # source_row, targetid, split   (the frozen split)
  aion_targetids_ra_dec_split_dr10_south.csv  # targetid, ra, dec, split (for fetching images)
```

### The merged source catalog

`erosita_spectra_merged_32k.hdf5` (~32k rows) is the eROSITA × DESI cross-match. Each row holds the
DESI spectrum (`spectra`, `spectra_ivar`, shared `spectra_lambda`), `redshift`, WISE fluxes
(`flux_w1/2/3`), the eROSITA broad-band flux (`ml_flux_1`), and the target coordinates
(`target_ra`, `target_dec`). From these, staging derives the regression targets
`log_ml_flux_1 = log10(ML_FLUX_1)` and `log_lx` (the log X-ray luminosity, via a Planck18 luminosity
distance). To rebuild it, cross-match the DESI DR1 and eROSITA DR1 catalogs on sky position and join
the WISE photometry.

### The image cutouts

Each target has one `griz` FITS cutout (bands `DES-G/R/I/Z`, 160 × 160 px at 0.262″/px) under
`fits_pool/<targetid>.fits`. Coordinates for every target are in
`aion_targetids_ra_dec_split_dr10_south.csv`; fetch each cutout from the Legacy Survey cutout service,
e.g.:

```text
https://www.legacysurvey.org/viewer/cutout.fits?ra=<RA>&dec=<DEC>&layer=ls-dr10&pixscale=0.262&bands=griz&size=160
```

## Building the staged splits

With the raw layout in place:

```bash
python -m shareable_aion_flow.main prepare-data --overwrite
```

This filters to rows with a valid image and finite targets, then writes
`data/staged/desi_{train,val,test}.hdf5` plus a `summary.json`. The split is the frozen 80/10/10
assignment in `aion_tvsplit_manifest.csv` — grouped by `targetid` (seed 42) so repeated observations
of a source never cross folds. For the image-backed four-modality model the resulting sizes are:

| Split | Sources |
|---|---:|
| train | 24,614 |
| val | 3,094 |
| test | 3,054 |

A quick smoke test stages a handful of sources without needing AION or zuko:

```bash
python -m shareable_aion_flow.main prepare-data --output-dir /tmp/smoke --limit 12 --overwrite
```
